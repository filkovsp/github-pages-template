# Lesson 1 — Homework

Complete the tasks below after reading the Lesson 1 classwork pages.

## Instructions

1. Clone the repository or download a copy.
2. Open the JavaScript files in this directory.
3. Complete each task where indicated.
4. Run your files with Node.js, or use a browser console where appropriate.
5. Commit your work on your own branch if your course instructor asks you to do so.

## Tasks

### Task 1 — Personal introduction

Open `task-1.js`.

- Create variables for your name, age, and whether you enjoy programming.
- Use `const` or `let` appropriately.
- Print the values with `console.log()`.

### Task 2 — Simple calculations

Open `task-2.js`.

- Declare two numeric variables.
- Calculate their sum, difference, product, and quotient.
- Print each result with a descriptive label.

## Completion checklist

- [ ] I used `const` and `let` appropriately.
- [ ] I can explain the values stored in my variables.
- [ ] I ran both JavaScript files and checked the output.
