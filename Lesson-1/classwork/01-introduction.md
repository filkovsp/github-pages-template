# What is JavaScript?

JavaScript is a programming language commonly used to make websites interactive.
It can run in a web browser and in environments such as Node.js.

---

## What can it do?

- Respond to clicks, keyboard input, and other browser events.
- Update page content without reloading the page.
- Validate forms and work with data.
- Build server-side applications and command-line tools.

---

## Where does it run?

**In the browser:** JavaScript can interact with the page through browser APIs such as the DOM.

**Outside the browser:** Runtime environments such as Node.js let JavaScript run on a computer or server.

---

## A first example

```javascript
const message = "Hello, world!";
console.log(message);
```

`console.log()` writes a message to the developer console (or the terminal in Node.js).

---
